# Python & Data Science Fundamentals

A beginner-friendly project covering Python programming fundamentals and basic Data Science concepts using NumPy and Pandas.

## 📌 Topics Covered

* Variables and Data Types
* Arithmetic Operations
* Lists and Dictionaries
* Conditional Statements
* For and While Loops
* Functions
* File Handling
* NumPy
* Pandas
* DataFrames
* Data Analysis
* Data Filtering
* Basic Data Science Concepts

## 🛠️ Technologies Used

* Python
* NumPy
* Pandas
* VS Code

## 🚀 How to Run

1. Install Python.
2. Open the project folder in VS Code.
3. Install the required libraries:

```bash
pip install numpy pandas
```

4. Run the program:

```bash
python internone.py
```
